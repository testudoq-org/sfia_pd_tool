# Debugging Instructions

1. To debug in Chrome:
   - Select "DEV Launch Chrome" or "PRD Launch Chrome" from the Debug dropdown.
   - Press F5 to start debugging. Chrome should launch automatically.

2. To debug in Edge:
   - Select "DEV Build and Launch Edge" or "PRD Launch Edge" from the Debug dropdown.
   - Press F5 to start debugging. Edge should launch automatically.
